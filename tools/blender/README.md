Blender scripts for the book's rendered figures.

`dof_scene.py` builds the three-drone scene from cached BlenderKit assets (two drone models, DJI Mavic 3 Classic, Oak Wood2 floor, Simple bricks wall, old-forest-green-tree HDR) and renders `chapters/media/image-formation/`. Run with Blender 5.2:`blender -b --python dof_scene.py -- full`.
